# Project rules

## Code comments

- Write all code comments in English: `//`, `/* */`, JSX `{/* */}`, and `#` comments in config files such as `.gitignore` and `.env.example`.
- Do not translate user-facing text. Button labels, error messages, receipt and ticket text, and staff instructions stay in the language the users read (mostly Russian).
- A comment may quote real data or printed text in its original language, e.g. a table name like `"2 терраса"` or the printed word `"ОТМЕНА"`.
