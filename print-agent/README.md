# Программа печати (print-agent)

Работает на компьютере в баре. Каждые несколько секунд забирает с сервера задания
печати и отправляет их на термопринтеры:

- **заказы на бар и счета** → принтер бара;
- **заказы на кухню** → принтер кухни.

Чек рисуется картинкой (через встроенный Chrome) и печатается растром ESC/POS,
поэтому иврит, кириллица и логотип печатаются на любом ESC/POS-принтере
без настройки кодировок.

## 1. Сервер

В `.env` сервера (и на хостинге) добавьте длинную случайную строку:

```
PRINT_AGENT_TOKEN=придумайте-длинный-случайный-токен
```

Без него программа печати не подключится, а индикатор принтеров на странице
`/orders` не показывается.

## 2. Установка на компьютер в баре

1. Установите Node.js LTS с https://nodejs.org (версия 18 или новее).
2. Скопируйте папку `print-agent` на компьютер.
3. В этой папке выполните: `npm install` (скачает Chrome для отрисовки чеков, ~150 МБ).
4. Скопируйте `config.example.json` в `config.json` и заполните его (см. ниже).
5. Проверка: `npm run test-print` — на каждом принтере выйдет пробный чек.
6. Запуск: `npm start` (Windows — двойной клик по `start-windows.bat`).

## 3. config.json

```json
{
  "server": "https://адрес-вашего-api",
  "token": "тот же PRINT_AGENT_TOKEN",
  "pollSeconds": 3,
  "printers": [
    { "name": "Бар",   "roles": ["bar", "bills"], "paper": "58", "connection": { ... } },
    { "name": "Кухня", "roles": ["kitchen"],      "paper": "58", "connection": { ... } }
  ]
}
```

- `roles` — что печатает принтер: `kitchen`, `bar`, `bills` (счета). Один принтер может печатать несколько ролей.
- `paper` — ширина ленты: `"58"` или `"80"`.
- `cut` — `false`, если у принтера нет ножа (по умолчанию `true`; принтеры без ножа команду просто игнорируют).
- `chromePath` (необязательно) — путь к уже установленному Chrome вместо скачанного.

### Варианты `connection`

**Сетевой принтер (LAN / Wi-Fi)** — самый надёжный вариант для кухни, которая стоит отдельно:

```json
{ "type": "tcp", "host": "192.168.1.50", "port": 9100 }
```

IP-адрес принтер печатает сам на тестовой странице (обычно — удержать кнопку FEED
при включении). Закрепите этот адрес за принтером в настройках роутера, чтобы он не менялся.

**USB или Bluetooth, Windows.** Установите принтер в Windows с драйвером из комплекта,
затем: *Параметры → Принтеры → принтер → Свойства принтера → Доступ →
«Общий доступ к данному принтеру»*, сетевое имя без пробелов, например `POS58BAR`.

```json
{ "type": "windows-share", "share": "POS58BAR" }
```

**USB или Bluetooth, macOS / Linux.** Добавьте принтер в системе
(драйвер «Generic / Raw» подходит), имя очереди смотрите командой `lpstat -p`:

```json
{ "type": "cups", "name": "POS58_bar" }
```

**Проверка без принтера** — чеки сохраняются картинками в папку:

```json
{ "type": "file", "dir": "./printed" }
```

## 4. Автозапуск (Windows)

Нажмите `Win+R`, введите `shell:startup`, положите туда ярлык на `start-windows.bat`.
Скрипт сам перезапускает программу, если она остановилась. Отключите для компьютера
спящий режим.

## Как это работает

- «На кухню» / «На бар» на странице заказов → задание в очередь → программа печатает его на нужном принтере.
- «Закрыть стол» → счёт сразу уходит на принтер счетов. «Печать счёта» — напечатать ещё раз.
- Если принтер недоступен, задание повторяется до 5 раз с паузой; задания старше 30 минут не печатаются.
- В шапке `/orders` индикатор: зелёный — принтеры на связи; красный — программа не отвечает
  или есть застрявшие задания (по нажатию — список с кнопкой «Повторить»).
- Одновременно можно запустить программу на нескольких компьютерах (например, отдельно на кухне) —
  каждое задание напечатается один раз.
